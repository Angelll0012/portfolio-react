# Creative Portfolio

## Project Description
Creative Portfolio is a React application designed to showcase creative projects. Users can browse projects, search for projects by title or category, and add new projects.

## Features
- Display a list of creative projects.
- Search projects by title or category.
- Add new projects using a form.
- Responsive layout for different screen sizes.
- Reusable React components.

## Technologies Used
- React
- JavaScript
- HTML
- CSS
- Vite
